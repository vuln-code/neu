
# C++ Pattern Printer 🎨

This is a small C++ program where the user can choose a pattern (like triangle, square, pyramid, etc.) and the program prints that pattern on the screen.

## 🔧 What This Program Does

- When you run the program, it asks the user to choose which pattern they want to print.
- Based on the user's choice, the pattern is displayed using stars (`*`).
- It’s a good project to practice using loops (like `for` or `while`) and basic logic in C++.

## 🚀 How To Use It

1. Open the `main.cpp` file in any C++ compiler or IDE (like Code::Blocks, Visual Studio, or a terminal).
2. Compile and run the code.
3. Enter the number for the pattern you want.
4. The pattern will be printed on the screen.
